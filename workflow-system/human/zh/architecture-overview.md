# 架构概述

系统架构：4 层层级、阶段原语、质量门机制。

## 系统概述

DevolaFlow 使用 4 层代理层级编排复杂工作流。

## 4 层层级

| 层级 | 角色 | 上下文预算 |
|------|------|----------|
| 项目代理 | 分派阶段，跟踪状态 | ~3K tokens |
| 阶段代理 | 分解为批次，运行质量门 | ~5K tokens |
| 批次代理 | 并行分派任务 | ~4K tokens |
| 任务代理 | 执行实际工作 | ~8K tokens |

## 质量门机制
