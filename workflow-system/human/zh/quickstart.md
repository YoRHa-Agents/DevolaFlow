# 快速入门指南

10 分钟内开始使用 DevolaFlow。

## 前置条件

- Python 3.11+
- pip

## 安装

```bash
pip install -e ".[dev]"
```

## 你的第一个工作流

1. 运行 `detect-repo-mode` 识别仓库类型
2. 运行 `validate-template --all` 验证模板有效性
3. 根据任务选择工作流类型
4. 遵循 4 层层级：项目代理分派阶段代理
