Accessibility

Reduced-motion fallbacks, WCAG contrast targets, keyboard focus, bilingual switching.

  • All animations honour `prefers-reduced-motion: reduce`.
  • Body text meets WCAG AA on both themes; new tokens were chosen for AA.
  • Every interactive control is keyboard-focusable with visible focus ring.
  • EN/ZH switch is one click; preference persists in localStorage.
