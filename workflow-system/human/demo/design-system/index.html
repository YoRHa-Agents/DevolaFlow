02 / FOUNDATIONS

Typography and layout policy

The system uses one deliberate type stack and a compact spacing, radius, and border vocabulary.

spacing · 4px base
Use the six shared steps. Prefer whitespace over nested containers.
radius · 3 / 6 / 10px
Controls stay compact; larger radii are reserved for broad preview surfaces.
border · 1px by default
Borders carry hierarchy. Four-pixel left rules are reserved for semantic emphasis.
elevation · two restrained levels
Shadows clarify overlays and active surfaces; they never simulate glow.

03 / STATES

Semantic states

Color is paired with explicit language and a stable border treatment. A scalar score is never the primary message.

READY

Evidence available and threshold met

REVIEW

Attention without failure

INSUFFICIENT

Required evidence is unavailable

04 / COMPONENTS

Shared component examples

Components stay shallow, rectangular, and evidence-first. These are live shared classes, not screenshots.

05 / MOTION

Motion restraint

Motion is brief, finite, and explanatory: no looping glow, decorative scanlines, or hover transforms. Replay is always user-initiated.

06 / ACCESS

Accessibility is part of the component contract

The shared layer defines the baseline; page-local CSS may specialize layout without weakening it.

  • focus-visibleA high-contrast 3px focus ring appears for keyboard navigation.
  • 44pxButtons, links acting as controls, and navigation targets meet the minimum touch size.
  • prefers-reduced-motionAnimation and transition duration collapses while content remains complete.
  • Light / DarkSemantic contrast is maintained in both themes; state meaning never relies on color alone.
  • EN / ZHNavigation, interaction feedback, labels, and explanations switch together.
  • KeyboardNative buttons power token copy and motion replay; no pointer-only interaction is required.
