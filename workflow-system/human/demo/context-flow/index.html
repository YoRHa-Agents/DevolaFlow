RUNTIME CONTROL · evidence → gate → checkpoint

A passing round requires item-level proof

L0 checks selected checklist IDs, configured commands, blocker closure, and ownership conflicts before writing a checkpoint or choosing a bounded next round.

  • Aevidence/verbatim command and artifact evidence
  • BChecklist gateIO-1…IO-4 checked independently
  • Ccheckpointonly after the selected round passes
  • Dharness ledgertelemetry retained for cross-change evaluation; not a fake live feed

ESCALATION UP · Task → Wave → Project → Human

Failures are classified and routes never skip a layer

Recoverable failures retry only within the declared ceiling. Blocking or fatal failures become an EscalationEvent and move upward until resolved.
