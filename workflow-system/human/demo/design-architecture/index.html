      • 05
        Measured return path

        Evidence · Harness

        Dispatch telemetry records measured token use, budgets, constraint counts, quantifiable ratios, layer attribution, and round context in append-only JSONL. The built-in harness aggregates that ledger and deterministic repository signals into six W-3 dimensions, then emits READY, NOT_READY, or explicit INSUFFICIENT.

        Tuning proposals remain immutable and hash-bound. Applying one requires a separate explicit approval artifact; evaluation alone never mutates runtime configuration.

      02 / LAYERS

      Select one runtime layer

      The selector has exactly three states. Each state shows the layer's context budget, authority, evidence responsibility, and implementation boundary.

      L0 · Project · ~5K

      Owns the round decision

      Receives
      User goal, checklist, preflight, round status, and bounded evidence summaries.
      Controls
      Round selection, Wave partitioning, gates, reinforcement, checkpoints, archive, and human reporting.
      Boundary
      Dispatches delegated work; never implements it or replaces item evidence with a score.

      L1 · Wave · ~5K

      Coordinates a bounded partition

      Receives
      A selected task list, dependency map, ownership map, and predecessor evidence summaries.
      Controls
      Conflict checks, pairwise-disjoint Task dispatch, and item-level evidence aggregation.
      Boundary
      May dispatch no more than five Tasks; never edits Task output or marks checklist items complete.

      L2 · Task · ~8K

      Implements one atomic assignment

      Receives
      One TaskDispatch, owned and read-only paths, relevant contracts, rules, and bounded predecessor facts.
      Controls
      Owned-file changes, bounded self-verification, and a lean evidence-bearing StatusReport.
      Boundary
      Only implementation layer; never spawns agents, self-scores, or writes outside ownership.

      03 / GUARDRAILS

      Three distinctions that prevent drift

      The architecture stays understandable when knowledge, executable control, and generated projection remain separate.

      Seed ≠ runtime
      A seed contributes checklist decomposition knowledge. source_stages preserves where that knowledge came from; only change-driven executes the lifecycle.
      Compiled ≠ authored
      Governance edits begin in .rules/*.mdc. AGENTS.md, repo-governance.mdc, and STYLE-RULES.md are compiler outputs protected by drift checks.
      Evidence ≠ verdict shortcut
      Item-level checks and artifacts decide round completion. Harness dimensions and a composite support release readiness; unavailable inputs stay INSUFFICIENT.
