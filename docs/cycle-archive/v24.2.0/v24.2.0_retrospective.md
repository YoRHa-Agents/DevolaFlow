## 3. What we learned

**Two fields were doing one job, and the quieter one lost.** `refused` was
computed from a `findings` list that had accumulated results from two
unrelated phases: the moves, and the digest rendered after them. Nothing about
that is subtle in hindsight, and it survived a MAJOR plus a MINOR because the
digest only produces findings when a narration anchor breaks — a state no test
had reached while moves were also succeeding. The fix was a field, not logic.
The cost of finding it was a read-only audit that had no other purpose.

**A generated view must not be hostage to the prose above it.** `write_digest`
validated agent narration and returned early on any complaint, which meant the
ledger-derived table — the authoritative part, the part the digest exists for —
went unwritten because of a sentence. Withholding output as a way of signalling
a problem is a tempting pattern and almost always wrong when the withheld
output is what a reader depends on. Report and render.

**A test that never exercises the fix is decoration.** Both existing tests for
F-00 would have passed if `load_ledger_records` still raised on a retired gate
row. One asserted the writer refuses to emit the name; the other asserted the
frozenset's contents. Neither called the reader, which is where the outage was.
Coverage of a bug fix has to run the path that broke.

## 4. Deferred, with reasons

Five findings remain in `.local/tasks/v24.1-self-digest/parking/`:
`RISK-001` (blocker), `RISK-003` (major), and `RISK-005` through `RISK-007`
(minor).

`RISK-001` is the one that matters and it is deliberately still open.
`apply_plan` moves a file and only then appends its ledger row; if the append
fails, the file is at its destination with nothing recording it, and `locate`,
`restore`, and `verify` all lose it. Fixing that means a journalled or
two-phase apply, which is a structural change to the apply contract. Bundling
it into a release whose only other content was separating two result fields
would have buried a durability change inside an unrelated MINOR.
