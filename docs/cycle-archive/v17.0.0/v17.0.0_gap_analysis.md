## 3. 轮次分解（可控/可分解/可迭代）

| 轮次 | 内容 | 门禁 |
|---|---|---|
| **R1 清理** | A1–A7 全部移除/合并（原子：删除+迁移+测试同 PR） | 全套件绿；dead-apis 0；覆盖率 ≥80%；W-17 记账 |
| **R2 边界收紧** | B1 host 桥 + 强制开关解耦；B2 层预算断言 | 新增强制路径 e2e；旧行为回归零破坏（默认模式明确） |
| **R3 注入优化** | B3 slice 接通 + 遥测扩字段；fold 政策扩展（G-TOK-3） | 真实账本显示 slice_savings>0；A-2 字节门禁不动 |
| **R4 focus/loop** | B4 goal/loop 适配层 + 自动 checkpoint/resume | 中断恢复 e2e；session-start resume 冒烟 |
| **R5 模型边界** | B6 容量/阈值 guard 化 + probe 模型刷新 + W-24.2 裁决 | 提案闭环覆写路径测试；probe 多模型画像落盘 |
| **R6 npm** | C1–C3 包 + CI + C-6 位点 | `npm pack` 干跑绿；publish 需用户凭据（人工触点） |
| **R7 证据收口** | B5：全周期真实账本 → W-16 结算 → v17 vs v16 效率对照表 → W-3 评估 | 六维交叉校验 + 效率表正向或如实报告 |

R1 与 R6 可并行；R2→R3→R7 有依赖链；每轮独立 PR、独立 gate、可单独回滚。

## 4. 用户决策（2026-08-25 已拍板）

1. 周期版本：**v17.0.0 MAJOR**（R1–R7 全量，解锁 A 组承诺移除）。
2. npm 包名：**`@yorha-agents/devola-flow`**（scoped）。publish 时需用户注册 org 包名并配置 `NPM_TOKEN` secret。
3. S-1 host 桥形态：**实做 host 桥，覆盖五个 host** — Cursor hooks + Claude Code hooks + **Codex + DSH + Kimi(KimiCode)**。R2 需先调研三个新增 host 的钩子/拦截机制（Codex 的 hooks 能力、DSH sidecar 的接入面、KimiCode 的 hooks 支持），无原生钩子的 host 降级为 prompt-side + 事后审计（`check_file_ownership` 批扫），形态差异在 R2 设计中明示。
4. 发布流：v16.0.0 已直接合并发版（PR #183 → main，tag v16.0.0）；v17 各轮从 main 分支，每轮独立 PR。
