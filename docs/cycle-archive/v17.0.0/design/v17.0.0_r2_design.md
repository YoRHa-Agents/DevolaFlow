## 2. 设计决策

### D-R2-1 统一桥核 `devolaflow.hostbridge`

新包 `src/devolaflow/hostbridge/`：

* `normalize.py` — 各 host stdin JSON → `BridgeEvent(host, kind: file_write|shell, path, command, cwd, agent_kind: main|subagent)`。
* `decision.py` — `decide(event, repo_root) -> BridgeDecision(allow: bool, reason, audit)`：
  1. 快路径：`DEVOLAFLOW_HOST_ENFORCE != "1"` → allow（零 IO，R5 strict）。
  2. `file_write`：解析 `.local/.agent/active/*/owned_files.txt`（无活动 change → allow）；调 `run_hooks("file_write", {path, owned_files}, strict=False)`，CFO006 blocker → deny。S-8 §2/§3 豁免（change 文件夹自身 + handoff）与 `runtime_wiring` 同构。
  3. `shell`：调 `run_hooks("pre_shell_call", {cmd, cwd})` — **首个生产调用方**；结果为 advisory（allow + 改写元数据入审计），不阻断（S-1 shell 阻断需层角色证据，本轮只审计）。
  4. 审计账本：追加 `.local/telemetry/hostbridge.jsonl`（host、kind、path/cmd 摘要、verdict、时延）— 供 R7 真实账本。
* `__main__.py` — `python -m devolaflow.hostbridge --host {cursor,claude,codex,kimi,dsh}`；按 host 输出（cursor: JSON permission；其余: exit 0/2 + stderr）。**内部异常 fail-open**（allow + 账本记 error，S-5 不静默）。
* `install.py` — `python -m devolaflow.hostbridge install <host>`：生成/合并宿主配置（cursor/claude/codex 写项目文件；kimi 打印 TOML 片段）。

### D-R2-2 强制开关解耦（W-20 新 flag）

新 env flag **`DEVOLAFLOW_HOST_ENFORCE`**（R5 strict `"1"`）：

* 复用测试：`DEVOLAFLOW_AGENT_WORKSPACE` 激活的是 workspace 脚手架 + 框架内 `fire_*` 适配器；host 桥拦截是**不同运行面**（host 工具事件），需独立开关（可只强制不脚手架、或只脚手架不强制）→ 行为正交，允许新 flag。
* 授权三件套：`env-flags.md` §2.18 同 PR 登记；`tests/test_hostbridge_disabled_is_noop.py` 零 IO 测试；CHANGELOG 周期收口时点名（ghost pin 先行）。
* 既有 `DEVOLAFLOW_AGENT_WORKSPACE` 语义不变（框架路径照旧）。

### D-R2-3 仓库自食（dogfood）配置

`.cursor/hooks.json` + `.cursor/hooks/devola-boundary.sh`、`.claude/settings.json` hooks 块、`.codex/hooks.json` 入库。桥脚本 bash 前置快路径（flag 非 "1" 直接 allow，不起 Python），全部 fail-open（不设 failClosed），保证未开启用户零影响。

### D-R2-4 DSH 桥 = cordis 插件

`packages/dsh-plugin/`（纯 ESM `.mjs`，无构建步）：`tools/pre-execute` 瀑布内 spawn `python -m devolaflow.hostbridge --host dsh`，deny 时返回 `{kind:'deny', reason}`；python 不可用/超时 → allow（fail-open）。R2 只出包骨架 + 冒烟，npm 发布走 R6 通道另行。

### D-R2-5 层预算断言（B2）

新 `lifecycle/assert_layer_budget.py::assert_layer_token_budget(payload, *, strict=False)`：

* 由 dispatch payload 解析目标层（复用 `LAYER_ATTRIBUTION_ALIASES` 归一；解析不出 → pass，向后兼容）。
* `estimate_tokens(stable_yaml(payload))` 对照 `harness.telemetry.LAYER_TOKEN_BUDGETS[layer]`（单一所有者；`context_profiles.yaml` meta 与常量加 parity 测试）。
* 超支 → `ALB001` 违例（severity `error`）：`pre_dispatch` 默认 strict 下阻断，lite 警告。**不变异 payload**。
* 注册为 `PRE_DISPATCH_EVENT` extra（`lifecycle/__init__.py`），排在既有 extras 之后。

### D-R2-6 文档

`scripts/scaffold_reference.py` 新增 `references/host-bridges.md`（C-7 四件套由脚本代办），承载五桥矩阵、降级注记、安装指引;`env-flags.md` §2.18 登记新 flag。

## 6. CHANGELOG 备存文本（周期收口 rollup 时采用）

### R2-T1（hostbridge）

- **NEW package `devolaflow.hostbridge`** (G17-B1, §D-R2-1): five-host boundary bridge
  (Cursor / Claude Code / Codex / KimiCode / DSH) routing host tool events into the
  lifecycle hook chain — `file_write` enforces the S-8 owned-files union of active
  changes (CFO006 blocker → host-protocol deny); `shell` is advisory-only and gives
  `pre_shell_call` its FIRST production caller. Fail-open everywhere; enforced
  decisions append to the `.local/telemetry/hostbridge.jsonl` audit ledger.
- **Operator-visible behavior change**: NEW env flag `DEVOLAFLOW_HOST_ENFORCE`
  (R5 strict `"1"`; W-20 §3-justified vs `DEVOLAFLOW_AGENT_WORKSPACE` — host tool
  events vs framework write adapters + scaffolding; `references/env-flags.md` §2.18).
  Flag absent → zero-IO byte-identical no-op (`tests/test_hostbridge_disabled_is_noop.py`).
- **Dogfood host configs committed** (§D-R2-3): `.cursor/hooks.json`,
  `.claude/settings.json`, `.codex/hooks.json` + sibling `devola-boundary.sh`
  wrappers with pure-bash fast path; idempotent regeneration via
  `python -m devolaflow.hostbridge install <host>`; `install kimi` prints the
  user-level `[[hooks]]` TOML snippet.
- **NEW `packages/dsh-plugin/`** (`@yorha-agents/devola-flow-dsh` 0.1.0 pre-release,
  §D-R2-4): cordis `tools/pre-execute` plugin; deny on bridge exit 2; 5s-timeout
  fail-open; npm publication rides the R6 channel.
- **NEW reference `references/host-bridges.md`** (large tier, 26th SF-4 canonical).

### R2-T2（层预算断言）

- **Added — layer-token-budget dispatch assertion (G17-B2, D-R2-5).** New `pre_dispatch`
  extra `devolaflow.lifecycle.assert_layer_budget::assert_layer_token_budget` gives
  `meta.layer_token_budgets` its first dispatch-time consumer: the payload's token size
  (telemetry's `estimate_tokens(stable_yaml(payload))` pipeline; budgets single-owned by
  `harness.telemetry.LAYER_TOKEN_BUDGETS`, YAML↔constant parity pinned) is asserted
  against the target layer's budget (L0 5000 / L1 5000 / L2 8000). Overruns surface
  `ALB001` (severity `error`) — blocking under the strict `pre_dispatch` emission
  default, warning in lite mode. Layer attribution mirrors `build_dispatch_record`;
  payloads without resolvable layer info always pass. Non-mutating — S-10 byte-identity
  preserved. `harness.telemetry.stable_yaml` exported as the public measurement serializer.
