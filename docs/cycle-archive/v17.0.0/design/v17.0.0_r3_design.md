## 1. 事实基线（调研锚点）

* `AGENTS.md` 全量 `estimate_tokens` = **12,267**（43 条规则，Style 0 条）；host 自动注入全量语料，遥测 `tokens_injected_measured` 只量 dispatch YAML → host 注入完全不可见（G17-B3 成立）。
* `select_agents_md_slice`（`agents_md_slice.py:330`）默认 ON（YAML `meta.agents_md_slice.enabled: true`）、自带 `full_tokens`/`slice_savings_pct` 计算（hotfix 70.3% / research 81.8% / feature 34.9%），但生产链路仅 `selector_cli --show-slice` 一处调用；`select_context` 与 `generate_round_dispatch` 均未接。
* 遥测账本（harness JSONL）不受 A-2 布局治理（A-2 只管 lean dispatch payload）；新增账本字段安全。
* advisory fold 现策：`should_fold_advisory(model_hint)` 硬编码 `{"quality","frontier"}`（`tiers.py:370`）。

## 2. 设计决策

### D-R3-1 slice 接入 select_context（加性返回键）

`select_context` 末尾（行为块折叠之后、return 之前）调用 `select_agents_md_slice(task_type, profiles_path=...)`，以**加性键** `agents_md_slice` 挂入返回 dict（子集：`profile_name`、`slice_enabled`、`total_tokens`、`full_tokens`、`slice_savings_pct`、`included_rules` 数量）。**不改** `assembled_text` / `total_tokens`（既有 pin 不动；slice 是 host 注入面的账目与建议，不是 SKILL 组装文本的一部分）。失败（AGENTS.md 缺失等）→ WARNING + 键置空 dict（S-5）。

### D-R3-2 遥测账本扩两字段

`build_dispatch_record` 增：

* `host_rule_tokens`：host 规则语料注入量 = slice 结果的 `full_tokens`（当前现实：host 注入全量 AGENTS.md）。模块级缓存（mtime+path key）避免每条记录重读。
* `slice_savings_pct`：该 dispatch 任务类型下配置 slice 的可得节省；task type 从 payload 既有字段解析（实现者按 lean-dispatch 现字段定；解析不出 → 0.0，`host_rule_tokens` 回退全量估计）。

聚合器：两字段为**可选**（不进 `_REQUIRED_FIELDS`，旧账本兼容）；`tokens` 段增 `host_rule_tokens_mean`、`slice_savings_pct_mean`（仅在记录携带时计算）。R3 gate「真实账本显示 slice_savings>0」由 e2e 用可切片任务类型出真记录验证。

### D-R3-3 fold 政策扩展（G-TOK-3 最小面）

`should_fold_advisory` 改为配置驱动：读 `context_profiles.yaml` `meta.advisory_fold.model_tiers`（列表，精确匹配保持大小写敏感）；**配置缺失时默认 `["quality","frontier"]`，行为字节不变**。折叠面不扩（rules.focus/acceptance 折叠证据不足，留给 R5 模型边界轮按 probe 证据裁决）。

### D-R3-4 文档修正

`references/env-flags.md` §2.11 的 slice flag owner 引用已陈旧（A4 shim 退役后 owner 是 `agents_md_slice.py::_AGENTS_MD_SLICE_ENV_FLAG`），同 PR 修正。
