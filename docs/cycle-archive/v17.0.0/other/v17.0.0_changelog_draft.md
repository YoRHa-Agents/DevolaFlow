- **`devolaflow.nines` package deleted** (deprecated at v16.0.0): the two test modules went with it; `gate/complexity_detector.py` drops the nines-alias constants and uses canonical `COMPLEXITY_INSPECTION_TIMEOUT_SECONDS`.

- **23 ADR-006 module-split shims retired**: call sites import owner modules directly; the S-10-named keepers (`populate_cascade_gate_fields` et al.) are preserved byte-identically.
- **`cascade_min_layers` legacy-4 reinterpretation removed** (G17-A5): declared values validate at face value; the v16 WARNING+fold compatibility path is gone (revised A-7.1).
- **Repo-wide L3 → L2 naming sweep**; `LAYER_ATTRIBUTION_ALIASES` single-owner in `agent_workspace/layers.py` (telemetry aliases derive from it per A-5).
- **48 stale `DEFAULT_ALLOWLIST` entries purged** from `scripts/detect_dead_apis.py`.
- Net effect: −143 lines of tests alone (−149 deleted, +6 pins), plus the deleted packages/schemas/shims.

Fail-open everywhere; enforced decisions append to the `.local/telemetry/hostbridge.jsonl` audit ledger.

- **Dogfood host configs committed**: `.cursor/hooks.json`, `.claude/settings.json`, `.codex/hooks.json` + sibling `devola-boundary.sh` wrappers with pure-bash fast path; idempotent regeneration via `python -m devolaflow.hostbridge install <host>`; `install kimi` prints the user-level `[[hooks]]` TOML snippet.
- **NEW `packages/dsh-plugin/`** (`@yorha-agents/devola-flow-dsh` 0.1.0 pre-release): cordis `tools/pre-execute` plugin; deny on bridge exit 2; 5s-timeout fail-open; npm publication rides the R6 channel. - **Layer-token-budget dispatch assertion** (G17-B2): new `pre_dispatch` extra `assert_layer_token_budget` gives `meta.layer_token_budgets` its first dispatch-time consumer — payload token size asserted against the target layer's budget (L0 5000 / L1 5000 / L2 8000); overruns surface `ALB001` (blocking in strict, warning in lite).
