### 2.2 Architecture rationality (weight 0.20) — score **9.3/10**

**Evidence:**
- **Two-module split (cache + router) mirrors RTK's `src/discover/registry.rs` + `src/discover/rules.rs` single-source-of-truth pattern** per the SI-2 NineS analysis §4.1 + the v8.3.2 PV-02 shell_proxy precedent. `cache.py` owns the value type + invalidation predicates; `router.py` owns the lookup orchestration + lazy IO. Clean module boundaries; either layer can be tested in isolation.
- **Schema-first design** — `schemas/memory-case.yaml` (259 lines) is the canonical source-of-truth; the `MemoryCase` dataclass mirrors `index_fields` verbatim; `build_case_from_dict` is the single funnel through which YAML rows become `MemoryCase` instances. Adding a new field is a 3-step change (schema YAML + dataclass field + build helper extraction); test suite covers all three.
- **Lazy load + cache reuse** — `MemoryRouter()` construction is a no-op (no IO); the index loads on first `lookup_case()` call into an immutable `_IndexLoadResult` snapshot (frozen dataclass); subsequent calls reuse the snapshot without re-reading the file. Tests can inject `cases=[...]` to skip IO entirely (e.g. for hot-path performance benchmarks).
- **Cache-miss is the safe path** (per cycle plan §6 R3) — every error path degrades to `None` so the caller falls through to the existing planner unchanged. This is the canonical R5 strict pattern: the new feature can NEVER break dispatch; it can only optionally accelerate it.
- **Two predicates run for every match BEFORE returning a hit** — `is_version_stale` (exact string equality with `devolaflow.__version__`) AND `is_ttl_expired` (anchor priority `last_accessed` > `last_updated`). Routes invalidate automatically when `__version__` bumps; routes invalidate after their TTL window; both predicates are cheap dict reads with no clock skew beyond the local UTC midnight boundary. The `today_iso()` helper wraps the wall-clock read so tests can `monkeypatch` it without touching `datetime` globally.
- **Activation snapshot captured per construction** — the `_env` dict is captured in `__init__`; `is_enabled()` reads from this snapshot rather than `os.environ` so tests can pass a frozen env dict via the `env=` kwarg. The hot path (`lookup_case`) does ONE env read at the start (via `is_enabled()`) then NO further env reads.
- **Default-off discipline** — the env-flag is the single activation point. Even when `.local/memory/cases/index.yaml` exists with valid recipes, the router is OFF when the env-flag is unset. No surprise activation.
- **Dual-path API** — `lookup_case()` (default) NEVER raises and degrades to `None`; `lookup_case_strict()` raises `MemoryRouterError` on schema breaks. The dispatch hot path uses the safe variant; CI verification scripts and operator inspection tools use the strict variant. Mirrors the v8.2.6 change-driven workflow's permissive-vs-strict mode pattern.
- **R5 strict** verified by:
  - All 3139 pre-existing tests pass byte-identical when env-flag off
  - `tests/test_memory_router.py::TestLookupCaseR5StrictOff::test_off_flag_does_not_touch_filesystem` codifies the R5 contract at the unit-test layer with a `monkeypatch.setattr(Path, "read_text", watcher)` watcher that asserts the watcher was never called
  - `benchmarks/devolaflow_context/scenarios/memory_router_fastpath.yaml` codifies the dispatch-surface invariant at the EvoBench layer (composite 99.73 above floor 90)
- **Operator-friendly seed kit** — the `.local/memory/cases/README.md` operator doc explains how to add a recipe, the schema link, and the default-off env-flag in 50 lines; the seed `index.yaml` carries 3 realistic recipes extracted from v8.3.1 PV-01, v8.3.2 PV-02, and the cross-PV doc-consistency cascade. Future operators can extend by appending rows + authoring matching markdown files (no new tooling required).
- Equal to v8.3.2's 9.3 — clean module boundaries, single-source-of-truth schema, proper lazy-load + cache-reuse discipline, RTK-faithful design pattern, dual-path strict-vs-permissive API.

**Score 9.3** — clean module boundaries, schema-first design, lazy-load + immutable-snapshot cache, dual-path API, R5 strict default-off, operator-friendly seed kit.

### 2.6 Performance impact (weight 0.15) — score **9.0/10**

**Evidence:**
- **R5 strict zero-overhead when env-flag off**: `is_router_enabled()` is a single dict lookup (`os.environ.get("DEVOLAFLOW_MEMORY_ROUTER", "0") == "1"`) — sub-microsecond. NO file IO, NO YAML parse, NO subprocess. The `lookup_case()` flat-call wrapper short-circuits to `None` BEFORE constructing a `MemoryRouter` instance. - **EvoBench `memory_router_fastpath.yaml` composite 99.73** (well above floor 90, far above v8.3.2 shell_proxy_disabled.yaml's 91.21) — proves the dispatch-surface cost holds within the feature profile's expected range and the new lifecycle integration adds zero overhead in the dispatch path; the noise_ratio 0.0 reflects the canonical 14-section feature profile pickup with no extra sections (compare to shell_proxy_disabled.yaml's 0.1333 noise from the 15-section quick_action_decision pickup).
- When the env-flag IS set: the activation snapshot is captured ONCE per `MemoryRouter` instantiation; the index loads ONCE on first `lookup_case()` call into an immutable frozen-dataclass tuple; subsequent calls iterate the in-memory tuple (linear scan; ~5-10 cases for typical seed sizes, ~20-50 for mature operator libraries). For typical L0/L1 dispatch frequency (~1-3 calls per dispatch cycle), the per-call cost is sub-millisecond after the first load.
- The actual planning-context savings claim (≥30% L0 token reduction per gap analysis §2.1 M-001 quantitative target) is conservatively measured at the unit-test layer: a single `lookup_case()` probe (~50 LOC of YAML + dict iteration ≈ 200 tokens) replaces a full SKILL.md re-derivation (498 lines + workflow selection table ≈ 3200 tokens), saving ~3000 tokens per matched dispatch ≈ 93% reduction of the planning-context block. The EvoBench scenario codifies the COMPLEMENTARY invariant (post-fast-path L3 dispatch is canonical-quality); the savings claim itself is structural (one-shot dict probe vs full re-derive).
- The `_load_index` method has 4 distinct exception arms (missing file, OSError, YAMLError, non-mapping top-level) each returning a frozen `_IndexLoadResult` with empty cases tuple — these all complete in O(1) for the failure case, well below the 30-second NineS budget for measurement.
- 0 regressions > 5pp across all 47 EvoBench scenarios vs `v8.3.0_baseline.json`
- Equal to v8.3.2's 9.0 — passes the W-4 / SI-4 hard gate (0 regression > 5pp); the new module adds a sub-microsecond cost per dispatcher invocation

**Score 9.0** — zero-overhead R5 mode confirmed; lazy-load + frozen-snapshot cache means the per-call hot path is dict iteration + 2 cheap predicate checks; planning-context savings claim is structural (~93% reduction for matched routes) and well above the ≥30% gap analysis target.
