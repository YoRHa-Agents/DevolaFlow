## 4. Key learnings

- **Upstream-surface verification pays off.** Fetching `impeccable@2.3.2`'s `cli/bin/cli.js` confirmed `impeccable --version` works and `skills install` auto-detects the harness (no `--ai` flag) — this drove the correct `init_targets:[auto]` registry design instead of blindly copying the ui-pro/codegraph `{ai_platform}` template.
- **Count-pin sprawl is the dominant cost of a "+1 plugin / +1 template" cycle.** Adding the 6th plugin + 23rd template cascaded into ~10 existing count-pin tests + 5 README/workflow-skill literals + generate_human_docs. Running the full suite early (and a clean-main worktree diff) was essential to separate genuine regressions from pre-existing failures.
- **W-20 substring guards can false-positive.** `test_v9_2_0_new_symbols_have_coverage` asserts the literal `DEVOLAFLOW_` never appears in `init_project.py`; merely *referencing* the existing flag in a comment tripped it. Resolution: keep the reuse-first rationale in CHANGELOG / env-flags.md, not in the module source.
- **W-16 "regen at the PV that first drifts" worked cleanly.** The SKILL.md +3 lines + `impeccable_integration` block lifted `collapse_l0_l3_simple` +8.87 (an improvement); regenerating `v13.0.0_baseline.json` + retargeting the sanity test + the `_newest_baseline_path` pin was the full fix.
