## Version map (8 versions)

The cycle ships as **four PATCH (PV-01..PV-04) + two MINOR (PV-05..PV-06) + one MAJOR (PV-07) + one optional sustaining PATCH (PV-08)**. Rationale per `v9.0.0_gap_analysis.md` §1.2 line 69:
