## 2. S02 T02 — Adapter Config Schema Parity Check

### 2.1 Canonical schema

Per `src/devolaflow/adapters/data_driven.py::DataDrivenAdapter` docstring (lines 57-81), the v1 YAML config schema is:

```yaml
name: <id>                                          # REQUIRED
display_name: <str>                                 # optional
version_added: <semver>                             # optional
tier: core | high_priority | tier_1 | tier_2        # optional, default tier_1
output:                                             # REQUIRED
  base_dir: <relative output dir under dist/<name>/>
  files:
    - source: <path under agent_dir>
      target: <path under base_dir>
      transform: copy | copy_tree | copy_with_frontmatter
               | strip_frontmatter | keep_sections
      # keep_sections-only options:
      keep_sections: [<heading substring>, ...]
      header_prefix: "<string prepended to output>"
      include_frontmatter: false
frontmatter:                                        # optional
  inject:
    platform: <str>
budget:                                             # optional
  type: lines | chars
  max: <int>
  target_file: <relative path>
```

### 2.2 Existing Tier-2 precedent

`adapter_configs/openclaw.yaml` is the only `tier: tier_2` example today (OSS OpenClaw gateway). It uses the plain copy pattern (SKILL.md + references) with a 500-line budget targeting SKILL.md. The 5 NEW enterprise adapters will mirror this pattern with adapter-specific `base_dir` values.

### 2.3 5 NEW adapter target surfaces (PV-08 scope)

| Adapter | base_dir | SKILL target | Budget | Rationale |
| --- | --- | --- | --- | --- |
| `jetbrains` | `.idea/devola-flow` | `SKILL.md` (copy_with_frontmatter) | lines 800 | JetBrains IDE family (IntelliJ/PyCharm/WebStorm/GoLand) stores per-project config under `.idea/`; the devola-flow skill drops into an `.idea/devola-flow/` bundle loaded by the IDE-side plugin (when authored). |

| `augment` | `.augment/rules` | `devola-flow.md` (strip_frontmatter) | lines 800 | Augment Code reads `.augment/rules/*.md` (single-file or multi-file) per the Augment docs; the mirror lands as `.augment/rules/devola-flow.md`. |
