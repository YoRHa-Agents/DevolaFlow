### D-3 — Handoff envelope auto-strip helper (MAJOR, telegraph from v12.4.0 retro §3 + §6 → PV-05)

**Symptom**: v12.4.0 PV-05 shipped `reject_subagent_banner_emission` lifecycle hook that DETECTS banner literals + `quality_score` keys in dispatch payloads but does NOT auto-strip them — operators currently get a WARNING + violation list and must manually scrub. Per v12.4.0 retro §3 deferral table row 4, a v12.5.0+ helper would close the auto-cleanup loop.

**Source evidence**: `.local/research/v12.4.0_retrospective.md` §3 row "Handoff envelope auto-strip helper" + §6 telegraph item 2.

**Fix scope**: NEW pure function `strip_l0_only_metadata(envelope: dict) -> dict` in `src/devolaflow/agent_workspace/handoff.py`. Contract:

* **Pure**: operates on a deep-copy of the input dict; never mutates input; never touches disk (S-9 append-only preserved — handoff envelopes on disk are written by callers, not by this helper)
* **Idempotent**: applying the helper twice produces the same output as applying it once
* **Permissive on absent keys**: dict without banner/quality_score keys returns deep-copy unchanged
* **S-5 explicit warn**: malformed input (non-dict, or banner literal in unexpected nesting) logs WARNING via `logging.getLogger(__name__)` rather than raising or silently dropping

**Closed-by**: PV-05. Tests: ~8 NEW in `tests/test_handoff_strip_metadata.py` (happy-path + idempotency + permissive on absent + S-5 warn-not-suppress + deep-copy invariant + companion-to-banner-hook integration test).

## 5 — Risks + mitigations

### R-1 — Codegraph CLI not installed in execution VM

The v12.5.0 cycle is implemented + tested in environments where `codegraph` CLI may not be installed. Tests MUST NOT assume `codegraph` is on `$PATH`. Mitigation: all `tests/test_codegraph.py` cases mock `subprocess.run` (or use a small fake-binary fixture); the degraded-mode contract is the documented fallback path anyway. The `_cli.py` thin wrapper raises a structured `CodegraphUnavailableError` that callers catch and downgrade to Read/Glob/Grep.

### R-2 — W-4 EvoBench baseline drift

Codegraph plugin metadata adds ~50 bytes per dispatch (the `config.codegraph_commands` NEST payload). PV-02 (commands.py refactor) and PV-04 (template wiring) both touch the W-4 critical path. Mitigation: run W-4 sweep at PV-02 + PV-03 + PV-04 close; per W-16 v12.3.0 PV-04 clarification, regenerate wholesale at the FIRST PV that drifts (otherwise defer to cycle close).

### R-3 — `canonical_order` drift via accidental new dispatch key

Plan asserts NO new dispatch keys; codegraph commands NEST under existing `config.codegraph_commands`. Mitigation: run `tests/test_layout_invariant_multi_baseline.py` after each PV that touches schemas/lean-dispatch.yaml or context_profiles.yaml; A-2.4 multi-baseline byte test gates each PV.

### R-4 — SF-4 reference-list drift

Adding `references/codegraph.md` (21 → 22) requires updating BOTH the SKILL.md Tier-2 navigation table AND the C-7 entry in `.rules/conventions.mdc` AND recompiling `AGENTS.md` + `.cursor/rules/repo-governance.mdc`. Mitigation: PV-05 commit MUST run `make compile-rules` AND `python -m pytest tests/test_no_ghost_features.py::test_rule_surfaces_compile_only -v` to gate compile-only drift.

### R-5 — SKILL.md exceeds 500-line ceiling

Target additions: ~+4 lines (Workspace Engagement row + Tier-2 table row + Quick Start note). Current 486 + 4 = 490, with 10 slots of headroom under C-4 < 500 ceiling. Mitigation: pre-PV-05 sanity check `wc -l workflow-system/agent/SKILL.md`; if > 495 after edits, trim cross-references rather than adding new prose.

### R-6 — Handoff helper accidentally mutates an on-disk envelope

The `strip_l0_only_metadata(envelope: dict) -> dict` helper operates on an in-memory dict only. Mitigation: tests assert input dict unchanged via `copy.deepcopy` comparison; the helper internally calls `copy.deepcopy(envelope)` before any field mutation; S-9 append-only is preserved because the helper is invoked by the WRITER pre-write, not by any reader.

### R-7 — W-17 test cap overrun

Plan estimates ~80 NEW tests across 6 PVs. Per-PV max is PV-03 at ~28 (under +30 cap). Cumulative ~69 NEW (under +150 cap). Mitigation: track delta after each PV via `git diff <previous-pv>..HEAD --stat -- tests/`. PV-05 mid-cycle audit confirmation per W-17.
