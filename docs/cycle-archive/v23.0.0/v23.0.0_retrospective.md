# v23.0.0 Retrospective

## Gaps identified

- `entrance.md` was guaranteed only on the canonical scaffold path; partial and
  direct task-folder writers could leave an incomplete workspace.
- Long-running external work had timeout rules but no explicit ready-work
  continuation contract.
- Preflight authorization and sibling continuation were separate lifecycle
  surfaces, so a local blocker could stop unrelated work.
- Dispatch budgets and configured slices existed without complete, host/layer
  token measurements.

## Implemented

- Made `entrance.md` a first-class artifact, added strict/lite runtime checks,
  and covered `.local/tasks/` linting and scaffolding.
- Added W-30 bounded-wait and selective-blocker-isolation rules and compiled
  them into the distributed rule surfaces.
- Added host/channel/layer token-injection records, captured-transcript
  ingestion, CLI probe channels, aggregation, and dispatch context telemetry.
- Added six-host fixture replay contracts and the operator calibration matrix.
- Slimmed the rule and skill surfaces while preserving layout, version, and
  host-adapter contracts.

## Deferred

The operator calibration matrix is intentionally external-process evidence.
Until all 120 cells complete and are imported, live token/quality deltas and
causal ROI remain `INSUFFICIENT`; fixture replay does not substitute for them.

## Key learnings

1. Artifact completeness must be enforced at creation and lifecycle boundaries,
   not only repaired by a later lint pass.
2. Waiting policy needs a scheduler-level state model, not only per-process
   timeouts.
3. Token optimization must preserve matched workload identity and provenance;
   configured savings are not measured savings.
4. Compiling rule sources after compression is mandatory because historical
   ghost audits pin exact normative phrases.
