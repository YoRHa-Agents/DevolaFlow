# v17.5.0 Local-Archive Gap Analysis

## Baseline

Repository evidence identifies package version `17.4.2` in both `pyproject.toml`
and `src/devolaflow/__init__.py`. The supplied design is finalized later-cycle
intent; this artifact authorizes no implementation by itself.

## Observed deficiencies (repository facts)

| Priority | Deficiency | Evidence |
|---|---|---|
| P0 | No reusable inventory, plan, or apply contract for `.local/tasks/`. | The design inventory finds no such API in `src/devolaflow/local/`, `workspace_context.py`, or the existing archive modules. |
| P0 | Task lifecycle, cluster identity, destinations, and mappings are not machine-readable. | `src/devolaflow/local/workspace.py::generate_index` lists only immediate `.local/` directories. |
| P0 | No task-specific protection, strict clean check, or deletion boundary exists. | Existing W-19 research archiving and `ChangeStore` archive active-change artifacts, not task cleanup. |
| P1 | Flat/brownfield `.local/tasks/` layouts have no non-destructive adoption path. | `scan_workspace` deliberately does not enumerate task entries or archive mappings. |
| P1 | Reference repair and append-only move provenance are not part of a task move contract. | The design records these as missing cleanup-report capabilities. |
| P2 | No independent task-archive doctor/lint or declarative seed/reference wiring exists. | The existing `entropy-cleanup` seed has no task-cluster manifest, mapping, or deletion gate. |

## Proposed v17.5.0 file-level fixes (proposals)

1. **P0 runtime contract:** add `src/devolaflow/local/archive.py`, its focused
   schema under `schemas/`, and focused tests. The single owner should provide
   report-only inventory/planning, exact protected verdicts, approval-gated
   moves, index output, mapping emission, and strict clean checks.
2. **P0 operator surface:** extend `src/devolaflow/cli.py` and `pyproject.toml`
   with a bounded report/doctor command; add focused CLI/doctor tests. The
   default must be report-only and must never expose automatic deletion.
3. **P1 workflow wiring:** add a `local-archive` seed, reference, registry and
   install/SKILL wiring, plus current-cycle ghost coverage. Keep seed fields
   declarative and route behavior through the sole runtime owner.
4. **P1/P2 release evidence:** run focused tests, parity/ghost checks, coverage,
   lint/format, harness, version, skill, and release-preflight gates. Version
   and release-file edits remain a later release task, not Phase 0 work.

## Explicit non-goals

- Do not modify W-19 research archiving, `ChangeStore`/`ArchiveManager`, or
  existing `.local/.agent/` lifecycle semantics.
- Do not expand default `scan_workspace` or alter `generate_index` behavior.
- Do not change `schemas/lean-dispatch.yaml`, canonical order, cache witnesses,
  environment flags, plugin/host registries, or compiled rule surfaces.
- Do not delete task folders, clones, worktrees, generated output, or any
  repository content automatically; deletion remains operator-only.
- Do not create a fixed six-cluster manifest, silently rewrite arbitrary links,
  or claim that any proposed runtime, seed, rule, or release record exists.
