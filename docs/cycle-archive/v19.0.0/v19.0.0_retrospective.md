# v19.0.0 Retrospective — Full-Repo Review Loop v2

Cycle close: 2026-08-28. This retrospective records the W-7 close evidence
for the v19.0.0 MAJOR cycle. The source planning contract remains
`.local/tasks/make_full_review_coverage_improve/loop_plan_v2.md`.

## 1. Gaps identified

The v19 SI-1 gap analysis identified a cross-cutting full-repository review
rather than a single runtime feature. The principal gaps were:

- Four internal split facades failed direct-import compatibility checks.
- Release preflight did not force full legacy ghost coverage.
- Import-graph analysis missed module-execution imports inside compound blocks.
- Preflight acceptance-criteria generation and consolidation measurements were
  not pinned strongly enough.
- The CJK gate did not inventory every intended agent-facing surface.
- The per-module coverage floor, release dry-run/preflight alignment, and
  telemetry evidence needed explicit enforcement.
- The rule corpus needed inventory, a repository-relative restructuring map,
  second-audit verification, and only then approved simplification.
- Historical telemetry did not provide a matched v19 trend series. The fresh
  evaluator still reports aggregate historical measurement records as
  `INSUFFICIENT`, and no per-PV W-17 split is available.

The final rule refactor map and second audit preserved the evidence boundary:
external-consumer, installed-CLI, host-adapter, and direct operator-usage
evidence remained `INSUFFICIENT` where it could not be established. The
second audit also identified stale explanatory count/position statements and
the need to keep the frozen layout and Tier-A witnesses unchanged.

## 3. Deferred and why

- The W-17 observation remains a process finding: the evaluator reports
  `w17.value: 90` and `w17.score: 0.0`. A per-PV split was not available, so
  this retrospective does not fabricate one. The next cycle should capture
  the per-PV function delta at each PV boundary.
- Historical checklist, reversion/blocker, and matched baseline trends remain
  `INSUFFICIENT`. The v19 baseline is settled from the fresh report for
  preservation, but it does not create a before/after comparison.
- External-consumer and direct operator-usage validation remains deferred
  wherever repository evidence is absent. Compatibility surfaces remain in
  place rather than being deleted on internal-only evidence.
- DSH web/progress UI, Tier-C host retention, and the Pattern 3
  persistent-state pool remain deferred from the v19 gap-analysis decisions.
  They require separate scope and architecture evidence.
- `full-repo-review` remains an O-matrix candidate rather than a new seed;
  accepting it requires a new disposition and its required architecture
  evidence.
- Existing selector line-based fallback deprecation warnings remain visible.
  The release preflight recorded 21 test-core warnings and 16 ghost-full
  warnings; the second rule audit identified these as deprecation warnings,
  not failed checks. Migration to section-anchor lookups remains follow-up
  work.

## 4. Key learnings

1. Rule refactoring is safest when inventory, restructuring, and a second
   audit are separate artifacts. This made frozen Soul rules, canonical
   layout positions, generated surfaces, and enforcement mappings auditable
   before source edits.
2. Internal compatibility evidence is not external-use evidence. Keeping
   facades and legacy parameters is the correct disposition when external
   usage cannot be established.
3. Current evaluator probes and historical telemetry answer different
   questions. Current measurements can be recorded precisely, while missing
   matched history must remain `INSUFFICIENT`; creating a settled baseline
   does not justify an invented delta.
4. A passing release chain can coexist with a process finding. The W-17
   observation is useful precisely because it remains visible instead of
   being hidden by the passing test and preflight gates.
5. The next cycle should make per-PV telemetry capture and matched baseline
   collection first-class close inputs, reducing the remaining advisory
   evidence gaps without changing the frozen cache witnesses.
