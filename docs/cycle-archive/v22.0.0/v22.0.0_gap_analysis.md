# v22.0.0 SI-1 Gap Analysis

## Scope

Retire RTK and Si-Chip completely while preserving Codegraph as an advised
capability: default-installed, non-forced, automatically used when available,
and explicitly degraded to built-in repository search when absent.

## Gaps found

1. RTK was still represented by the shell proxy, command-mapping schema,
   `pre_shell_call`, installer fallback logic, and plugin registry entries.
2. Si-Chip was still represented by the bridge package, `post_skill_edit`,
   dogfood dispatch, workflow seed stages, and the iteration-delta release gate.
3. Codegraph's desired optional semantics were not explicit enough across the
   registry, probe, scaffold, workflow assertions, and fallback documentation.
4. Lifecycle and SI-10 tests and governance documents pinned the retired
   surfaces.

## Priority and proposed changes

- P0: remove RTK and Si-Chip runtime code and lifecycle wiring.
- P0: preserve the Codegraph runtime, set `tier: suggest` and
  `default_install: true`, and retain automatic fallback behavior.
- P1: update plugin registries, installer probes, workflow seeds, schemas,
  docs, functional matrix, and ghost audits.
- P1: recompile governance outputs and reduce the active lifecycle/SI-10
  contracts to their post-retirement surfaces.
- P2: publish v22.0.0 with reproducible test, harness, and release evidence.
