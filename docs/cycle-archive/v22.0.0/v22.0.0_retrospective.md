# v22.0.0 Retrospective

## Gaps identified

RTK and Si-Chip had integration surfaces beyond their plugin registry entries:
hooks, installer branches, workflow seeds, schemas, fixtures, release gates,
and historical ghost assertions. Codegraph needed a clearer distinction
between default installation and mandatory availability.

## Implemented

RTK and Si-Chip runtime packages and lifecycle integrations were removed.
The shell-proxy and Si-Chip-specific release surfaces were retired.
Codegraph remains `suggest` tier with `default_install: true`, automatic use
when available, and built-in fallback when unavailable. Governance, tests,
docs, and generated rule surfaces were synchronized.

## Deferred

Historical cycle archives, changelog history, and immutable benchmark witnesses
were retained intentionally. They are provenance records, not live dependency
surfaces.

## Learnings

Registry membership, runtime capability tier, and default installation are
separate contracts. A major removal must update all three independently while
keeping advised capabilities observable and degradable.
