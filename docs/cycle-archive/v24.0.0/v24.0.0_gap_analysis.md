# DevolaFlow v24.0.0 Gap Analysis — Workspace Compact + Risk-Parking/Judge

W-1 iteration planning gate for the v24.0.0 major cycle. Written before implementation;
this is the SI-2..SI-10 entry gate. Evidence labels follow the v23.1.0 convention:
**measured** (real command/file output), **configured** (declared in code/schema),
**estimated** (local tokenizer approximation), **INSUFFICIENT** (evidence absent —
never substituted with zero, default, or historical values).

## 1. Problem Statement

An operator-reported production failure mode from a long-running external task
(`.local/tasks/add_compact_and_new_files/add_compact_and_new_files.md`):

> 在任务经历了多轮次迭代后 devola 风格的任务文件体积变得非常大，工作区的历史 handoff
> 和多轮次 loop 产出体积也很大，agent 读取效率和性能都非常低，甚至出现报错
> prompt too large

The stated objective is explicitly **not** only lower skill-side token injection:

> 核心目标不再只是 devola-flow 本身的 token 注入变低，而是对上下文和工作区的管理能力要变强

The attached real-world artifact `sample-risk-parking.md` (217 lines, 37 recorded
update generations) is the concrete病例: it mixes four distinct concerns in one
Markdown file — ledger rows, historical沿革, user judgments, and agent recommendations.
The head quotation block alone consumes lines 1..131 (60% of the file) restating every
prior update. Reading one live risk requires loading the entire history of all risks.

## 3. Findings

Severity: **blocker** stops the cycle objective; **critical** breaks a core capability
or credibility claim; **major** leaves a significant coverage gap; **minor** is local.

### F-00 — critical: primary harness ledger is unreadable by its own evaluator

- Evidence: five `iteration-delta-gate` rows vs `telemetry.py:133-140`.
- Impact: W-2 entry reading, W-16 baseline settlement, and the six-axis gap inventory
  all abort on the primary ledger. Every v24 reading would silently rest on a derived
  artifact unless this is fixed.
- Note: the ledger is append-only in practice; the fix belongs in the reader's accepted
  gate vocabulary or an explicit quarantine path, not in rewriting history.

### F-01 — blocker: no workspace-compact capability exists

- Evidence: `rg` over `src/`, `workflow-system/agent/references/`, and
  `workflow-system/agent/templates/seeds/` finds zero `risk_parking`, `judge`, or
  workspace-level `compact` implementation. `directed_compact` is dispatch-text only.
- Impact: the reported `prompt too large` failure has no in-framework remedy. The only
  existing archive path (`devola-local-archive`) moves whole task folders across
  surfaces; it cannot shrink a folder that is still active.

### F-02 — blocker: `.local/.agent/` is out of scope for every archive adapter

- Evidence: `ARCHIVE_ADAPTERS` registers exactly `tasks`/`feedbacks`/`research`
  (`src/devolaflow/local/archive_adapters.py:227-258`); `.agent` and `human` are
  explicitly protected (`:76-81`); `references/local-archive.md:145-146,240-241` states
  local-archive MUST NOT own `.agent`.
- Impact: change folders and handoff — the two largest bloat sources — are reachable by
  no existing tool. A-5 forbids silently adding a fourth adapter; v24 needs its own
  single-owner module.

### F-03 — critical: handoff envelopes have no lifecycle beyond creation

- Evidence: `HandoffStore.write_envelope` uses exclusive `os.link`
  (`agent_workspace/handoff.py:388-442`); no delete or rotate API exists; the immutability
  contract is triple-pinned (S-9, `lifecycle/check_envelope_append_only.py`,
  `tests/test_handoff_envelope_immutable.py`).
- Impact: an N-round change accumulates unbounded envelopes with no index. Any relief
  requires either a Soul amendment (W-21 human-gated) or index-only mitigation.

### F-04 — critical: risk registration has no persistence surface

- Evidence: `StatusReport.findings` (`schemas/lean-report.yaml`) is the only risk channel
  and it is per-dispatch. Nothing persists a finding across rounds.
- Impact: the operator's unattended long-run scenario (park a non-blocking risk, keep
  going, adjudicate later) is unsupported; risks live in prose and rot into the kind of
  file `sample-risk-parking.md` became.

### F-05 — critical: user judgments have no single entry point

- Evidence: in the sample, decisions `D-R5.2`..`D-R24.3` are scattered across the risk
  document, preflight sections, and grill-round records, cross-referenced by prose
  pointers.
- Impact: no queue of pending decisions, no stable citation target, and no way for
  compact to know which content is a durable decision (never compress) versus historical
  narration (compressible).

### F-06 — major: no file- or directory-level token metering

- Evidence: `measure_context_tokens` is zero-IO by explicit contract
  (`context_tokens.py:61-71,190-210`).
- Impact: before/after compaction cannot be measured; the cycle's primary hard metric
  would be unverifiable.

### F-07 — major: `scan_workspace` cannot perceive bloat

- Evidence: `workspace_context.py:451-535` probes existence and counts, no byte or token
  dimension.
- Impact: L0 cannot proactively suggest compaction, so the failure mode is only
  discovered when a prompt already overflows.

### F-08 — major: artifact budgets do not cover accumulating surfaces

- Evidence: `CHECKLIST_ARTIFACT_BUDGETS` covers nine fixed artifacts
  (`_workspace_lint/common.py:18-38`); nothing bounds risk/judgment/event surfaces.
- Impact: splitting one bloated file into many unbounded files relocates the problem.

### F-09 — major: Python runtime is a silent prerequisite

- Evidence: SKILL.md documents a docs-only fallback when uv bootstrap fails; skills stay
  readable while `python -m devolaflow.*` and console scripts do not exist.
- Impact: a tool-mediated write contract has no meaning on a host without the runtime.
  The failure must be explicit and non-degrading, otherwise agents fall back to hand
  writing — reintroducing exactly the病 v24 exists to cure. Cross-referenced to the
  long-term binary-distribution feedback (`.local/feedbacks/feedback_for_v24.md`).

### F-10 — minor: cycle archive/baseline flow is unblocked but untested for v24

- Evidence: `.local/telemetry/baselines/` holds `harness_baseline_23.1.0.json` plus four
  older cycles; `scripts/archive_research_artifacts.py` exists.
- Impact: retention (current + previous two, Tier-C archive) needs an explicit v24 pass.
