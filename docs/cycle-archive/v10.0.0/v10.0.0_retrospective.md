## §4 — Key learnings (process improvements for v10.1.0+)

### §4.1 — What worked well

1. **bump_version.py is bulletproof for MAJOR jumps** — 9.7.0 → 10.0.0
   handled cleanly with no version-jump validation. 11 pattern replacements
   all succeeded; CP-3 sync verified by `tests/test_version.py` (16 / 19).
2. **`make sync-human-docs` is the canonical pipeline** — single command
   regenerates 16 EN/ZH guides. ST-3 bilingual completeness preserved
   automatically. The pre-existing `test_check_drift_cmd` lint is the
   right shape for this gate.
3. **57-feedback regression audit pattern** — the `audit_feedback_ac.py`
   pattern (extract artifacts → cross-check live state → categorize
   verdict) generalizes to any "have we regressed?" question. Reuse for
   v10.1.0+ feedback cycles.
4. **append-only schema discipline (A-2.2)** — schema v6 APPEND at
   position 17 was painless. The 9 historical multi-baseline byte tests
   (v7.0.0 → v9.7.0) all pass byte-identically because the new field's
   absence is canonical for round-1 dispatches.
5. **W-17 high-information vs scaffolding distinction** — the +66
   overshoot is OK because every new test is a meaningful contract pin.
   The mid-cycle audit precedent (W-17 §3) handles this gracefully.

### §4.2 — What didn't work as smoothly

1. **dataclass + spec_from_file_location pitfall** — the audit script
   tests initially failed because `dataclass` resolves field annotations
   via `sys.modules.get(cls.__module__).__dict__`, which fails when the
   module isn't registered. Fix: register in `sys.modules` BEFORE
   `exec_module()`. Documented in the test file's `_load_script_module()`.
2. **`_grep_symbol` fragility on test-file echo** — the test for "no
   hit" symbol initially false-positived because the test file itself
   contained the needle. Fix: construct the needle by string concatenation
   so the source file doesn't carry it as a contiguous substring.
3. **demo/index.html "automated" gate-type lint trip** — the test
   `test_demo_index_gate_types` forbids the literal word "automated"
   (a stale gate-type name). My v10.0.0 What's New section initially
   said "EvoBench-automated reports"; renamed to "EvoBench-generated
   reports" for the gate. **Lesson:** when prose-editing demo/index.html,
   pre-check the doc-consistency lints.
4. **`ruff check scripts/` was already drifting before v10.0.0** —
   3 pre-existing scripts (`archive_research_artifacts.py`,
   `generate_si3_evaluation.py`, `sync_cursor_skill.py`) have lint
   warnings. v10.0.0 didn't fix them (out of W-9 SI-10 scope which
   targets `src/` + `tests/`) but they're a v10.1.0 cleanup target.

### §4.3 — Process invariant strengthenings (codify in v10.1.0+ cycles)

1. **Pre-bump-version dry-run is mandatory** — `python scripts/bump_version.py X.Y.Z --dry-run` first to verify all 11 patterns match. Cheap belt-and-suspenders.
2. **Run `make sync-human-docs` immediately after `bump_version.py`** — closes the doc-drift surface in one shot. The 4 previously-failing tests after PV-01 were ALL downstream of the un-synced docs; all 4 closed at PV-03 with a single `make` invocation.
3. **`audit_feedback_ac.py` should run as a PR check at every release** — wire into CI as a release-preflight check (zero FAILs allowed at MAJOR; ≥95% addressed-or-deferred at MINOR). The script is fast (~2s on 57 files) and the test surface is fully isolated.
4. **For non-versioned guidance feedbacks (`feedback_for_skill.md` etc.)** — verdict by symbol survival, not CHANGELOG closure. The classifier was refined in v10.0.0 PV-02; future cycles inherit this.
5. **W-17 retrospective overshoot disposition: HIGH-INFORMATION vs SCAFFOLDING** — when the cap is exceeded, the retrospective §3 must explicitly distinguish "every test is a meaningful contract pin" (acceptable) from "lots of redundant assertion scaffolding" (the v8.0.0 anti-pattern). The v10.0.0 retrospective §3.4 sets the precedent.
6. **W-21 Soul-set telegraph cadence is real** — no Soul rule landed in v10.0.0 because none was telegraphed in v9.7.0's retrospective §3. v10.2.0 (cycle N+2) is the earliest opportunity for an S-11 candidate to land. The 2-cycle gap forces deliberate consideration.
