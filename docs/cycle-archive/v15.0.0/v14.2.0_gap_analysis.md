## §1 Executive summary + north-star framing

North star: **"在单独任务上做到极致"** — excellence of the single L3 task deliverable.

The two design reviews converge on one diagnosis, stated verbatim by the product review §8:
*"the product is an excellent task-INPUT machine attached to an underbuilt task-OUTPUT machine"*
(input quality 8/10, output verification 4/10). The repo review's §8 adds the dual constraint:
the governance apparatus consumes the very context budget that was supposed to buy single-task
focus (always-applied rule text loaded 2–3×, ~22% of SKILL.md Tier-1 is ceremony), and
maintenance gravity (baselines, ghost-audit, version fan-out) grows O(version-count) while L3
capacity does not.

The ladder therefore spends its budget in this order:

1. **v14.2.x** — delete duplicate prompt mass and doc drift (zero behavior change; the single
   largest per-dispatch token win is the F-R1/F-R7 stub conversion).
2. **v14.3.0** — OUTPUT closure I: give L3 evidence a transport (`self_check`, `ac_results`,
   `diff_stats`), an artifact-quality rubric (evidence-only per v15-ADR-007), and permissive
   `file_write`/`task_stop` hook wiring (per v15-ADR-003).
3. **v14.4.0** — intra-task convergence + AC coverage: the input machinery starts verifying its
   own outputs (`gate.intra_task_convergence` NEST, AC-v2 metric runners, `ac_generation`
   extension, surgical_scope diff verifier).
4. **v14.5.0** — governance debt + ADR-approved refactors (ghost-audit decomposition, scorer/
   selector split, SKILL IA pass, D-5 CHANGELOG lint, timeout defaults).
5. **v15.0.0** — strict-defaults flip + template Phase B collapse + rule-diet + S-11 evaluation;
   final eval ≥ 9.5.

41 consolidated gaps: **5 P0 · 12 P1 · 22 P2 · 2 P3**. 7 ADRs authored; 1 review-proposed ADR
(product ADR-4, dedup ledger) evaluated and **dropped** — it fails the "hard to reverse" gate
condition per the product review's own §7 analysis.
