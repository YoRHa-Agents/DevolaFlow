## 4. 关键学习

1. **回滚契约要与编号系统一起评审**：S-1 R1 被否不是因为正向措辞，而是回滚文本在新编号下会禁止唯一实施层——「保留旧文字」不等于「保守回滚」，混合态必须整体阻断（R2 §6 双 tuple 定律）。
2. **历史指标不做发明式映射**：NineS 25 项指标不能诚实折成六维；改用其当时实际参与生成的 v15 最终 W-3 伴随向量（`historical_w3_hybrid_companion_v15_final`）做交叉校验，方法先注册后看差值。
3. **可量化率是产品信号不是测试信号**：交叉校验最初 FAIL（架构维差 1.97）暴露的是 fixture 的 lean `accept` 条目缺机器镜像——修的是可追溯性（68/95），不是改指标口径。
4. **环境敏感测试要修在测试环境侧**：`python`→`python3` 是生产可移植缺陷（改注册表），而系统 python3<3.11 的开发机差异用测试侧 PATH 前置解决（与 `test_install_sh` 同法），两类修复不能混用。
5. **W-17 记账靠合并不靠删除**：三次无损测试函数合并（probe/proposal/fixtures 各 −1）+ 改名豁免立据，使 PV +23/30、累计 ≤148/150——预算纪律不牺牲断言覆盖。
6. **遥测证据要走生产路径**：评估账本由 `load_harness_fixtures` + `build_dispatch_record` 生成（canonical fixture workload），而非手写合成 JSON——provenance 记录在评估工件内。
