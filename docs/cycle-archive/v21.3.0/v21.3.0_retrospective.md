## Key learnings

1. A `READY` result from a prior evaluator run is not a fresh closeout
   result when the source ledger is missing.
2. Preserving exact JSON bytes and metadata makes the evidence boundary
   auditable; it does not repair missing raw inputs.
3. Quantifiable and unquantifiable constraint accounting must remain
   separate. The `120/140` measurement is a blocker, not a justification
   for a `>=0.9` claim.
4. W-16 settlement must be performed only from an actual available ledger;
   leaving the baseline absent is safer than manufacturing one.

## Close disposition

This is a partial, evidence-preserving closeout. The evaluation and
retrospective are available, while the fresh post-release evaluation,
W-16 settlement, and any archive claim depending on that settlement remain
blocked by missing raw telemetry.
