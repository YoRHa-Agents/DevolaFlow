## §1 — Cycle objective

Deliver on the v10.2.0 user mandate by (a) deep-reviewing the plugin auto-install + daily-upgrade machinery shipped in v9.4.0 with end-to-end verification (not just mocked unit tests), (b) formally integrating Si-Chip such that `run_dogfood_cycle` is reachable from L0/L1 dispatch and the `iteration_delta ≥ +0.10` gate fires in CI, (c) running NineS deep-analysis on the self-repo with Si-Chip iteration-effectiveness validation, (d) iterating multi-round with one PATCH bump per round per the user mandate "每次bump一个patch", and (e) closing the cycle as a MINOR bump to v10.3.0 with a single PR carrying the entire trajectory. The v9.5.0 OA-1..OA-5 deferred backlog is the primary input the cycle is formally integrating.
