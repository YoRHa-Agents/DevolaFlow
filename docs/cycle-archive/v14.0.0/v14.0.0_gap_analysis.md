## 2. Priority ranking

1. **D-1** — immutable input anchor; the feedback's stated "重点" (immutability + regression value). The headline of direction 1.
2. **D-2** — concise convergence output; direction 2's anti-flooding digest, a separate artifact from the agent dashboard.
3. **D-3** — human↔agent separation + de-pollution (relocate `sichip_deferred_*` off the human dir; resolve the TRACKER aspirational-vs-real gap); the cross-cutting boundary both D-1 and D-2 sit inside.
