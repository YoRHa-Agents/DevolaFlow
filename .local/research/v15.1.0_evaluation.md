## §2 Dimension notes (evidence-first)

### §2.1 Code quality — 9.2

* Shell + Python changes all landed with paired tests: `install.sh` rewrite
  (manifest-driven, update version-compare, uninstall) is covered by
  `tests/test_install_script.py` E2E harness (fake-curl network isolation);
  scaffold/init changes covered by `tests/test_cli_local_commands.py` +
  `tests/test_init_project.py`.
* S-5 debt REMOVED rather than added: #178 made rule-tree download failures
  visible (fail-count warning), made `auto`/`all` targets propagate
  `install_local` failure, and gave `ScaffoldStructureError` a FAIL+exit-1
  path at all three entry points.
* `ruff check` / `ruff format --check` green across `src/ tests/` on every PR.
* Deduction: two review findings (silent `dl || true`, unhandled
  `ScaffoldStructureError`) shipped in the B/C wave and needed the follow-up
  #178 — caught by review, not by the authoring PRs' own tests.

### §2.2 Architecture rationality — 9.0

* A-5 honoured: `workflow-system/agent/manifest.yaml` became the single owner
  for installable-file lists; `install.sh`, `sync_cursor_skill.py`, and
  `devola-init` all derive from it (three-consumer parity linted by
  `tests/test_install_manifest.py`).
* Scaffold structural contract got a single owner
  (`local/workspace.py::verify_structure`) reused by `devola-init doctor` —
  no second checker was invented.
* Cursor rules dedup (#177) is a governance-surface correction, not a new
  mechanism: one compile-config flag flip, recompile, contract pinned in
  `tests/ghost/test_features_v15_0.py`.
* Deduction: the wave intentionally did NOT touch the biggest known
  architectural gap (G1/G2 — 4-layer mandatory cascade with 1/4-viable tool
  support); that is gated on direction-lock D-1/D-2/D-3 owner sign-off, so
  scoring here reflects "did the right thing within scope", not end-state.

### §2.3 Test adequacy — 9.2

  compliant; counted `264d2c2..main`).

  "git is the only required dependency" claim.
* Adapter coverage went 4 → 12 tested adapters (parametrized, counts as

### §2.4 Maintainability — 9.3

  adding a reference is now a one-line manifest edit linted end-to-end
  (C-7 chain: file + `_SF4_REFERENCE_SET` + SKILL row + manifest entry).
