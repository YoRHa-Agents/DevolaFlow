**Owned files in PV-02 / PV-03:** `reference-dependencies.yaml` (caveman entry).

#### D-R-2 — `superpowers` skill catalog is stale (missing 4 NEW skills) *(MAJOR doc drift)*

**Source:** `/home/agent/reference/superpowers/skills/` listing, deep-analyzed at PV-01.
**Surface:** `reference-dependencies.yaml` `superpowers.key_patterns`.
**Evidence:** Current yaml does not cite `subagent-driven-development`, `verification-before-completion`, `dispatching-parallel-agents`, `using-git-worktrees`. The first two are directly relevant to DevolaFlow's L1/L2/L3 dispatch model (P1 / P3 / P4 invariants).

**Integration target:** `workflow-system/agent/references/team-roles.md` §"Specialist subagent patterns" — surface the **two-stage review (spec compliance → code quality)** pattern more prominently in DevolaFlow's L2 Wave dispatch documentation.

#### D-R-3 — `get-shit-done` stall-detection delta missing from gate rules *(MAJOR)*

**Source:** `get-shit-done/get-shit-done/references/gates.md` (deep-analyzed PV-01).
**Surface:** `reference-dependencies.yaml` `get-shit-done.key_patterns` + `workflow-system/agent/references/decomposition-gate.md` (the agent-facing gate spec).
**Evidence:** gsd's gates.md explicitly documents: *"The loop also escalates early if issue count does not decrease between consecutive iterations (stall detection)."* DevolaFlow's existing W-8 / SI-9 reinforcement mechanism mentions "If score stagnates for 2+ rounds → escalate to human" — partial coverage but the gsd nuance (issue count, not score) is more actionable.
**Fix:** Append a `key_patterns` bullet about stall detection (verbatim per C-3). Update `decomposition-gate.md` §"Convergence loop" with the 2-line clarification that stagnation can be measured by either composite score (DevolaFlow status quo) OR un-decreasing issue count (gsd 2026-04 refinement).

#### D-R-4 — `understand-anything` subdomain-graph merging not surfaced *(MAJOR)*

**Source:** `Understand-Anything/understand-anything-plugin/skills/understand/SKILL.md` Phase 0 step 4 (deep-analyzed PV-01).

**Fix:** Append `key_patterns` bullet for subdomain merging. Cross-link from `references/meta-framework.md` §"Codebase analysis primitives" if such section exists; otherwise cite from the research-only stage definition.
