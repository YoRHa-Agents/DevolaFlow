**Dimension notes**:

* **Code quality (9.5/10)** — 3420 tests pass, ruff clean, no new lint
  categories; new code ~+640 LOC with full docstring coverage and S-5 /
  R5 compliance; 9 new public-API symbols allowlisted under the same
  pattern as v8.2.5 ChangeStore / v8.2.8 memory_bridge.
* **Architecture rationality (9.5/10)** — NEST decision honoured per
  A-2.3 (compose field nests under filter rule; no new top-level
  dispatch key; 16-key canonical_order preserved); A-5 single-owner
  invariant preserved for the `CommandMapping` registry; A-2.4
  multi-baseline byte test passes for all 6 historical baselines.
* **Test adequacy (9.2/10)** — +27 NEW test functions (within +30 W-17
  cap); 53 EvoBench scenarios (up from 48); 4 R5 strict byte-identical
  invariants pinned at the pipeline orchestrator layer; 5×primitive
  env-flag opt-out contract pinned via parametrize. **-0.8** because
  the dispatcher integration layer (that consumes the pipeline and
  the 5 is_*_active helpers) is deferred to v9.x PVs — the helpers
  ship as API-ready but not yet wired.
* **Maintainability (9.3/10)** — 14th SF-4 canonical reference
  documents the unified surface (~408 LOC, within Tier-2 1000 line
  ceiling); SKILL.md +1 row (441 → 442); ADR-006 codifies the 4
  decisions + 4 alternatives + migration path verbatim.
* **Compatibility (9.5/10)** — zero changes to `schemas/lean-dispatch.yaml`;
  v1 command-mapping recipes continue to load byte-identically after
  v1 → v2 bump; v8.5.0 STANDARD/RELAXED users get byte-stable
  behaviour; v8.5.0 STRICT/AUDIT users get the opt-out path via 5
  env-flags. -0.5 because STRICT/AUDIT composite calculation DOES
  change (justified MINOR semver bump — see §4.1 / §4.2 of ADR-006).
* **Performance impact (8.8/10)** — R5 strict zero-IO invariants
  preserved (helpers return False in O(1) when profile flag False AND
  env-flag unset); CompressionPipeline construction is pure-Python no
  module-level state / no file IO / no subprocess; per-stage failure
  handling is logged at WARNING not CRITICAL so best-effort mode stays
  cheap. **-1.2** because the dispatcher integration isn't benchmarked
  yet — the stage-wrapper indirection adds ~1 call frame per stage
  vs calling the transform directly; unmeasured at release time.

**Composite**: **9.31 / 10** ≥ 8.5 MINOR threshold by **+0.81 pp**. **ACCEPT**.
