## 4. Key learnings

- **Parallel waves cause "already-present" confusion.** Co-instances of the same task repeatedly found work ALREADY done by a sibling: the `S7-converge` re-gate (dispatched against pre-Round-1 state) found both blocker fixes already landed by `S7-converge-1`; the SI-3 eval was overwritten mid-gate by a co-instance; and even THIS S8 retro/archive step hit it — the W-19 archive was already fully populated by a co-instance (12/12 `EXISTS`, 0 copied), so the source↔archive copies briefly diverged and had to be reconciled to one canonical version. Lesson: re-verify-then-no-op (don't re-edit, re-confirm and re-run) is the correct posture when a sibling may have raced ahead. **L0 action:** prune the stray duplicate artifacts left by the concurrent gate actor — `.local/research/v14.0.0_implementation_evaluation.md` (pre-convergence FAIL copy) + `_gate_cov_fresh.log` — keeping the canonical `v14.0.0_impl_evaluation.md` (post-convergence PASS 9.33); per eval advisory A5.
- **W-16 baseline regen must follow the version bump.** The wholesale regen had to run AFTER `bump_version.py 14.0.0` so the artifact is named `v14.0.0_baseline.json` (and the `_newest_baseline_path` pin retargets cleanly). Regenerating before the bump would have produced a misnamed baseline.
- **C-9 rows MUST flow through `.rules/conventions.mdc` + `make compile-rules`.** The `.local/human/` budget rows are a rule change; hand-editing the compiled `repo-governance.mdc` / `AGENTS.md` would trip the drift lint (`test_rule_surfaces_compile_only`). Edit the source `.mdc`, recompile, never the output.
- **Duplicated magic numbers defeat the SF-4 SSOT.** `tests/test_adapter_golden.py` hard-coded `assert len(actual) == 23`; the on-disk count, `_SF4_REFERENCE_SET`, SKILL nav, and CHANGELOG all agreed on **24** (`human-surface.md`), but the duplicated literal lagged — a lockstep miss the SSOT parity test could NOT catch because it lived outside the SSOT. The SI-3 gate caught it (B1); the durable fix (advisory A1) is to assert against `len(_SF4_REFERENCE_SET)` rather than re-pin the literal.
