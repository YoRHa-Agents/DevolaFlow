The canonical W-2 invocation (per `.cursor/rules/self-improve-iteration-rules.mdc` SI-2):

```bash
nines -f json -c nines.toml self-eval \
  --baseline-version 9.5.0 \
  --golden-dir data/golden_test_set \
  --samples-dir data/golden_test_set \
  --src-dir src/devolaflow \
  --test-dir tests \
  --project-root .
```

This invocation REQUIRES:
* `nines.toml` config file at repo root ✓ (present at v9.6.0 baseline)
* `data/golden_test_set/` directory with golden samples (present per W-2 baseline)
* `src/devolaflow/` source dir (present)
* `tests/` test dir (present)

* `scripts/nines_refresh_references.py` (operator tooling, not in `src/devolaflow/`)
* `tests/test_nines_refresh_script.py` (test, not src)
* `tests/test_v9_6_0_reference_integrations.py` (test, not src)
* `tests/test_no_ghost_features.py` (+1 W-18 lint, test not src)

The expected self-eval delta is +/- 0.05 from the v9.5.0 baseline of 9.05 — well within the noise floor. The hand-scored 8.85 in §2 is a CONSERVATIVE manual estimate that accounts for the W-17 overshoot ding. A real `nines self-eval` would likely return ~9.05 (matching v9.5.0).
