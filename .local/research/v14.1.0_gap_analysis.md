## (d) Finalized §6c join contract

- `TestOutcome{node_id, outcome, commit}` — frozen.
- `parse_pytest_report(report_path, *, commit="")` — consumes a pytest `--report-log` JSONL (one JSON
  object per line; keeps `{"$report_type":"TestReport","when":"call"}` records) → `{node-id: TestOutcome}`.
  S-5 loud: missing file → `FileNotFoundError`; malformed JSON line → `RequirementsTraceError`.
- `trace_requirements(requirements_path, *, test_results=None)`:
  - When `test_results` given AND a REQ `Acceptance` text names a pytest node-id present in the map →
    `passed→met` / else `unmet`; evidence verbatim `"<node_id> <PASS|FAIL> @ <commit>"` (C-3).
  - When absent / no resolvable node-id → matrix-`Status` derivation (backward compatible; v14.0.0
    callers stay byte-identical).
- Producing `test_results` (run pytest with `--report-log` + capture HEAD commit) is the **L0 caller's
  job**, documented in `references/human-surface.md`. The hook stays **opt-in** (no `DEFAULT_EVENTS`
  wiring — that would change the cache-stable lifecycle tuple and is out of scope for a MINOR).
