## §1 Executive Summary

DevolaFlow is a composable workflow meta-framework whose web demo currently surfaces *what the system runs* (architecture, visualizer, explorer, benchmarks) but does not yet surface *how the system thinks*. The v6.0.0 user feedback (`feedback_for_v6.2.0.md`) requested four currently absent or weak themes: (1) the **core design system** as a first-class showcase, (2) **modern animated visualisation of every framework chain**, (3) **clear, prominent depiction of context-flow routes** between layers, and (4) a **cross-version R&D timeline** that lets a reader see the journey from v3.x to v6.2.1.

**Design philosophy.** Treat Devola as a guardian narrator: every page should *show the watch* — gold accents marking active hand-offs, parchment and bunker tones for atmosphere, and motion that always reinforces hierarchy (downward dispatch, upward report). Quality gates are visual checkpoints, not invisible state. The 4-layer hierarchy (`L0 Project ~3K`, `L1 Stage ~5K`, `L2 Wave ~4K`, `L3 Task ~8K`) is the spine of nearly every diagram.

**What stays.** All five existing pages (landing, design-architecture, workflow-visualizer, stage-explorer, benchmark-results), the NieR/Devola identity (gold `#B8860B`, Devola red `#9B4444`, parchment `#F0EBE0`, dark "Bunker" mode), the Cinzel/Inter/JetBrains Mono typographic stack, the bilingual EN/ZH `data-i18n` mechanism in `shared/i18n.js`, the shared `shared/nav.js` glassmorphism nav, and the existing diamond section ornament + corner-mark hover. No content is regressed.

**What changes.** Four NEW pages are added under `workflow-system/human/demo/{design-system,framework-chain,context-flow,version-timeline}/`. The shared design tokens are *extended* (not replaced) with 5 new tokens for layered depth and gate-glow. Three new motion patterns are introduced (`pulse-dispatch`, `flow-down`, `verify-gate-glow`), all wrapped in the existing `prefers-reduced-motion` reset. The landing page gets four new entry tiles and an updated "What's New in v6.2.1" block. The shared `nav.js` gains four new entries; `i18n.js` gains the new keys (EN+ZH). No existing demo page is rewritten beyond nav inclusion and (optionally) one or two new tokens.

**Acceptance contract.** Section ordering and §4 acceptance bullets in this document are the *exact* contract S02 implementation tasks will copy verbatim. Every metric, version number, layer name, and feature name cited below comes verbatim from the read-only sources above; anything not directly sourced is marked `// TBD by L0`.

### §3.3 Motion vocabulary additions (3)

All three motion patterns MUST be wrapped by the existing `@media (prefers-reduced-motion: reduce)` block (`shared/styles.css` line 327) which sets `animation-duration: 0.01ms !important; transition-duration: 0.01ms !important;` — meaning these motions degrade gracefully to instant transitions for accessibility. No new `@media (prefers-reduced-motion)` rules are needed; the existing global rule covers the new `@keyframes` automatically.

| Motion id | Used by | Duration | Easing | Behaviour | Accessibility note |
|-----------|---------|----------|--------|-----------|---------------------|
| `pulse-dispatch` | `.dispatch-dot` (a small gold dot that travels down a route track) on context-flow page; layer→layer hand-off in framework-chain | `1.4s` | `cubic-bezier(.4,.0,.2,1)` | Translates a `--accent` 8px dot from top to bottom of the SVG route, with `opacity: 0 → 1 → 1 → 0` envelope so it appears, travels, and fades. Loop with `animation-iteration-count: infinite` until tab visibility hidden. | Suspended via `prefers-reduced-motion`. Static fallback shows a solid gold gradient on the route track so the route is still visible. |
| `flow-down`      | The full 4-layer L0→L1→L2→L3 cascade in framework-chain `#fc-hierarchy`; staggered card entrance on context-flow `#cf-dispatch` | `0.6s` per layer, `0.15s` stagger | `ease-out` | Each layer-node fades in from `opacity: 0; transform: translateY(-8px)` to `opacity: 1; transform: translateY(0)` in cascade. Stagger uses `animation-delay: calc(var(--layer-index) * 0.15s)` set inline by JS. Plays ONCE on initial scroll-into-view (use `IntersectionObserver`). | Suspended via `prefers-reduced-motion`; layers appear instantly in final state. |
| `verify-gate-glow` | `.gate-badge.is-pass` on framework-chain `#fc-gate`, context-flow `#cf-reinforcement`, version-timeline pass-state milestones | `2.0s` | `ease-in-out` | Pulses `box-shadow: 0 0 0 var(--gold-glow) → 0 0 24px var(--gold-glow) → 0 0 0 var(--gold-glow)` and `border-color: var(--accent) → var(--accent-hover) → var(--accent)`. Loop infinite while badge is in viewport. | Suspended via `prefers-reduced-motion`; static `box-shadow: 0 0 12px var(--gold-glow)` retained for non-animated emphasis. |

### §3.6 Accessibility baseline

- All NEW pages MUST keep `lang` on `<html>` synced via the existing `data-lang` mechanism (already in `shared/i18n.js`).
- All animation states MUST be reachable in static form (no info exclusively conveyed by motion).
- Colour pairings MUST keep WCAG AA on body text (the existing palette already does; the new tokens `--ink-deep` and `--ember-red` were chosen for this).
- All interactive controls (`button`, expandable card headers, motion replay buttons) MUST be keyboard-focusable and expose `aria-expanded` / `aria-controls` where they toggle disclosure.

## §9 Out-of-Scope and Deferred Items

The following are deliberately NOT in v6.3.0 web demo scope. Each is recorded so the next iteration's SI-1 planning gate can pick them up.

| Item | Reason for deferral |
|------|---------------------|
| WebGL or canvas-based 3D rendering of the framework chain | The four themes can be expressed in CSS + SVG + `IntersectionObserver`; introducing WebGL doubles the maintenance surface and breaks reduced-motion fallback patterns. |
| Reflowing the existing 4 sub-pages (architecture / visualizer / explorer / benchmarks) beyond nav inclusion and one or two new tokens | Spec is additive; out-of-band rewrites of stable pages would expand blast radius and obscure the four-theme deliverable. |
| EN ↔ ZH cultural tone variants beyond literal translation | DS-3 requires "same facts, same feature lists, same limits; wording may differ culturally" — this spec ships literal translations; nuanced re-tone is a follow-up. |
| Automated visual regression (Playwright snapshots of the 4 new pages) | Visual-regression infra is not yet a project capability (`tests/` has no Playwright dependency); add as separate iteration. |
| Live data feed from `benchmarks/devolaflow_context/baselines/` into the version-timeline | `versions.json` is a static, hand-curated artifact for v6.3.0; piping live JSON requires pages.yml CI changes (out of scope). |

| Additional adapter targets on the timeline (only the 11 confirmed in CHANGELOG are timeline-rendered) | Adding speculative or planned adapters violates Rule CO-2 (no unsourced metrics). |
