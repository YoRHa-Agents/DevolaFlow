# v9.0.0 SI-1 — Performance Trajectory (v2.x → v8.4.0)

> Sources: `.local/research/v9.0.0_version_history.md` + `benchmarks/devolaflow_context/baselines/`
> Date: 2026-04-23 | Author: L3 Task Agent (Test team)

## Summary

This trajectory aggregates 7 core numeric KPIs across ~80 versions / pre-release variants spanning v2.1.0 (2026-04-07) → v8.4.0 (2026-04-23), ~17 calendar days. **Test count** grew monotonically 254 → 3216 (12.7×) with one intentional retirement event (v6.0.2: 820 → 791 on deprecated-API removal). **NineS composite** shows a striking two-plateau + one-breakthrough pattern: 7-version plateau at 0.7405 (v5.4.2 → v6.1.0), tool-config-only breakthrough to 0.8805 at v6.1.1 (+18.9% with zero `src/` edits), then 6-measurement byte-stable 0.9050 across the v8.4.0 cycle. **EvoBench scenarios** grew 3 → 48 with disciplined ≤5pp regression guard (W-4 / SI-4) adopted operationally before being lifted to Soul tier. **SKILL.md** grew 293 → 499 lines, currently at 499/500 (1-line headroom — v9.0.0 compression cycle must reclaim budget). **Token budgets** remained stable at L0 ~3K / L1 ~5K / L2 ~4K / L3 ~8K across the entire window, with per-profile micro-tuning only. **Baseline files** show 22 `v*_baseline.json` entries with two wholesale-regen precedents (v6.0.5 3/29 → 29/29; v8.4.0 full rebase). **Rule taxonomy** reached 50 total rules at v8.3.0 (unchanged through v8.4.0).

Notable inflection events: v2.2.0 SKILL.md compression milestone (449→293, −34.7%); v6.0.3 dead-wire closure (highest-ROI intervention of v6.0); v6.1.1 NineS tool-config breakthrough; v8.0.0 13-patch cycle (largest single-release absorption); v8.4.0 byte-stable 6-measurement NineS (new stability pattern).
