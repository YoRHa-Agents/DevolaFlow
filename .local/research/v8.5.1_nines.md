**Status**: Manual analysis per W-2 ("NineS unavailable → manual analysis
following the same dimensions is acceptable but must be explicitly noted
as manual"). The R-6 fallback from v8.5.0 PV-05 (A1 `nines self-eval`
timeout upstream blocker) remains active; the NineS v3.3.0 binary does

v8.5.0 baseline (`.local/research/v8.5.0_nines.json` — composite
**0.9050** per PV-05 evaluation report §B.1) carries forward as the
cycle advisory baseline.

## A1 / A3 upstream blocker status (carry-forward from PV-05)

* **A1** — NineS v3.3.0 binary hardcodes `cov_timeout = 54s` despite our
  in-repo `[hygiene] cov_timeout = 180` key. Awaits NineS v3.4+ upstream
  fix. In-repo surface correct; no regression.
* **A3** — NineS v3.3.0 caches the index between invocations and does
  not honour our explicit `rebuild_index()` signal at `self-eval` time.
  Mechanism ships (Makefile target + Python entry-point); awaits
  upstream v3.4+ fix that fuses `analyze` + `self-eval` passes.

Both blockers are unchanged by PV-06; they will re-surface in the next
cycle's `self-eval` attempt when NineS v3.4 ships.
