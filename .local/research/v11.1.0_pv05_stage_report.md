  parallel for S01 + 1 sequential for S02 W05 architecture rule).

  invariant respected).

min wall-clock motivated the parallelization. **Result: all 3 L3 tasks
returned cleanly with zero file conflicts; integrated state PASS post-batch
(see §3.5).**

freeze + ADR-007 §"Soul-vs-Architecture" decision-rule alignment. Focused L3
