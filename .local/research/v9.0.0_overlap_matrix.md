## Detailed findings

### Finding #1 — Compression layers ship through 3 distinct entry surfaces despite shared semantics

- **Versions involved**: v3.9.0 (lean compression rules) → v4.0.0 (per-boundary defaults) → v4.1.0 (`compressor.py` runtime) → v7.0.1 (`truncate_tool_output`) → v7.0.2 (`summarise_predecessor` extractive) → v7.2.5 (`retrieval_query` kwarg) → v8.0.0 P-02 (`directed_compact`) → v8.0.0 P-12 + v8.2.0 PV-01 (abstractive A+B) → v8.3.4 (RTK-pattern command-output mapping in `shell_proxy/commands.py`).
- **Evidence** (verbatim from `.local/research/v9.0.0_version_history.md`):
  - v8.3.4 §file-level scope: *"Created `src/devolaflow/shell_proxy/commands.py` (~600 lines `CommandMapping` + `CommandMappingError` + `FilterRule` + `apply_local_recipe` + `load_command_mappings` + ..."*
  - v8.2.0 PV-01 §scope: *"`compressor.py::summarise_predecessor(mode='abstractive', llm_assist=True)` (no longer raises NotImplementedError). New `src/devolaflow/llm_client.py` (490 lines, MOCK provider default + 7 failure modes logged + Stage A fallback chain per S-5)."*
  - Cross-Era Pattern §11: *"Lean compression layered design — schema → boundary → runtime → benchmark → robustness (v3.9.0 → v4.1.1 template) ... encoded in current rules **C-2** (Lean Message Format) and **C-3** (Verbatim Extraction)."*
- **Why this is LAYERED-WITH-DEAD-WIRE rather than redundant**: `compressor.py` (predecessor + tool output + directed + abstractive A/B) + `llm_client.py` (provider abstraction) + `shell_proxy/commands.py` (output recipes) all transform L*→L* token streams but live in 3 packages with no shared `CompressionPipeline` interface. v8.4.0 carry-forward §3.3 already lists *"`shell_proxy/commands.py::apply_local_recipe` multi-pass filter chains (RTK supports filter composition per `filters.toml`) deferred to v8.4.x sustaining"* — confirming a dead-wire risk where command_mapping cannot compose with directed_compact today.
- **Proposed v9.0.0 direction**: **consolidate** — define `CompressionStage(name, transform, bypass_conditions, telemetry_key)` protocol; refactor `truncate_tool_output` / `summarise_predecessor` / `directed_compact` / `apply_local_recipe` / abstractive Stages A+B as concrete `CompressionStage` impls; add `CompressionPipeline.run(stages, payload)` orchestrator; preserve all current opt-in env-flags as stage-level bypass conditions (per Pattern 2 R5 strict).

- **Evidence** (verbatim):
