# v11.3.0 决策清单与方案路线（grill-with-docs 集成）

> **范围.** 本文是 v11.3.0 周期的中文决策档与执行路线总览，配套于英文 gap analysis（SI-1）+ retrospective（W-7）。所有结论均已通过 W-9 SI-10 7 步验证（4340 passed / 0 failed）；周期已经 ship，归档于本目录。

## 一、关键决策清单（10 项）

| # | 决策点 | 选择 | 理由（与对应规则） |
|---|---|---|---|
| **D-1** | 目标版本号 | **11.3.0**（跳过 11.2.0） | 你提供的 `feedback_for_v11.3.0.md` 文件命名直接锁定目标；`feedback_for_v11.4.0.md` 已预留下一周期（subagent-patterns-2026 → 面向 v12.0.0） |
| **D-2** | 工作流类型 | `nines-assisted`（research → design → impl → review → test → release） | 用户明确要求 NineS 分析（W-2 / SI-2）；多文件跨域改动属于 STANDARD+，需要 cascade（A-7 / `cascade_requirement`） |
| **D-3** | 规则归属层级 | **W-22 + W-23 落到 Workflow 层**，**不**新增 Soul 规则 | W-21 冻结 Soul 集为 10 条；本次新规则属"条件性 + 实现耦合"，符合 ADR-007 的 Soul-vs-Architecture 决策准则（与 A-7 同模式） |
| **D-4** | Grill Mode 与 Plan Mode 关系 | **平行正交**（parallel-orthogonal） | 二者可同时激活，互不阻塞；Plan Mode 字节稳定，无任何回归风险（保护已有 cache 前缀） |
| **D-5** | 激活机制 | **纯自然语言触发**（无新 env flag） | W-20 reuse-first：`classify_grill_intent` 返回三值枚举；env flag 数量保持 8 不变 |
| **D-6** | 自动写盘默认值 | **R5 strict default-OFF** | `CONTEXT.md` / `docs/adr/` 的写入需用户明确同意；只有 `infer_context_layout` 单一函数读盘；模块导入时零 IO |
| **D-7** | ADR 创建门控 | **3 条件门**（hard-to-reverse + surprising + real-trade-off）作为规范性义务 | `qualifies_as_adr()` 在 W-22.3 codify；防止 ADR sprawl；与 grill-with-docs 上游逐字对齐（CO-2 / C-3） |
| **D-8** | CONTEXT.md 与 spec.md 边界 | **词汇 vs 行为**严格分离 | CONTEXT.md = 词汇（domain experts 怎么称呼）；`.local/memory/specs/<domain>/spec.md` = 行为（系统怎么做）；W-23.4 codify，引用 A-4 |
| **D-9** | 历史 ADR 兼容 | **不**回填，仅适用于 v11.3.0+ 新 ADR | 历史 `.local/research/adr/` 用 `vN-ADR-NNN-slug.md`；新 ADR 用上游 `0001-slug.md`；`domain-awareness.md` §9 显式说明 |
| **D-10** | 测试增量 | 16-20 个新测试，加上 W-18 ghost-audit refresh | 远低于 W-17 +30/PV 上限；累计 ~+28 测试，离 +150/cycle 上限有大量 headroom |
