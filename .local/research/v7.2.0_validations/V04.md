### `references/execution-protocol.md`: new §7 "Wave Coordination Mode Selection (v7.2.0+)" (+53 lines)

Appended after the existing §6 (Progress Calculation, ends at line 425). Subsections:

- **§7 intro** (4 lines + 2 lines of source attribution) — sources the content to anthropic-coordination-blog §"Choosing and evolving between patterns" (2026-04-10), relevance=5.
- **§7.1 Pairwise Rubrics** — 4-row table containing the 4 pairwise switches **verbatim** (CO-2 compliance):
  1. Orchestrator-subagent vs. agent teams — "When subagents need to retain state across invocations, agent teams are the better fit."
  2. Orchestrator-subagent vs. message bus — "As conditional logic accumulates in the orchestrator to handle an expanding variety of cases, the message bus makes that routing explicit and extensible."
  3. Agent teams vs. shared state — "Once teammates need to communicate with each other rather than only share final results, shared state makes that more natural."
  4. Message bus vs. shared state — "If agents in a message bus system are publishing events to share findings rather than trigger actions, shared state is a better fit."
- **§7.2 Named Hybrid Recipes** — verbatim quotation of the two hybrid configurations:
  1. **orchestrator-subagent ⊕ shared-state** — "A common hybrid uses orchestrator-subagent for the overall workflow with shared state for a collaboration-heavy subtask."
  2. **message-bus ⊕ agent-teams** — "Another uses message bus for event routing with agent team-style workers handling each event type."
- **§7.3 Mapping to DevolaFlow** — 4-row table mapping each blog pattern to its DevolaFlow status (`orchestrator-subagent: Native via L0/L1/L2/L3` | `agent teams: Not modelled` | `message bus: Not modelled` | `shared state: Forbidden by P5` — verbatim P5 quote in the rationale cell).
- **§7.4 Applying the Recipes Inside DevolaFlow** — 7-line paragraph noting the orchestrator-subagent ⊕ shared-state recipe is a near-perfect characterisation of the existing `self-update` workflow research stage (T01–T07 parallel L3 task agents producing delta reports under `.local/research/`, with the directory acting as a read-only-for-downstream shared store so P5 stays preserved); instructs L2 Wave Agents picking `hybrid` mode to declare which named recipe applies in `topology_override` rationale.
